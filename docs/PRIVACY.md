# Rewards 助手隐私权政策

生效日期：2026-11-05

Rewards 助手是一款个人维护的非官方 Microsoft Rewards 浏览器扩展，与 Microsoft 无隶属或背书关系。本政策说明扩展会处理哪些数据、数据存放在哪里，以及用户如何控制这些数据。

## 扩展处理的数据

扩展只处理运行所必需的以下数据：

- **设置项**：是否执行搜索、每日活动、积分领取、每日自动执行，搜索次数、搜索间隔、加载后停留时间、是否打开首个搜索结果。这些设置保存在浏览器为扩展提供的同步存储（`chrome.storage.sync`）中，会随浏览器账号同步，供扩展在下次打开或后台定时执行时读取。旧版本可能仍留有不再使用的账号等级字段，扩展不会读取它来决定搜索次数。
- **任务状态**：本轮任务的阶段、已发起的搜索次数、各任务的执行结果（进行中、完成、失败、结果待确认、已取消等）。这些状态只保存在本机的扩展存储（`chrome.storage.local`）中，不参与同步，用于弹窗展示进度和结果。
- **Rewards 页面内容**：扩展在 `rewards.bing.com` 和 Bing 搜索结果页运行时，会读取页面中与积分任务、搜索框和结果链接相关的元素，用来判断任务是否可执行、结果是否出现。读取仅在本机页面内进行。

## 扩展不会做的事

- 不收集、不上传姓名、邮箱、地址、电话号码、账号密码、Cookie 或登录凭据。
- 不向开发者或第三方服务器发送设置、任务状态或页面内容。
- 不包含统计、广告、埋点或远程代码，不加载扩展包以外的脚本。
- 不出售、出租或向第三方传输用户数据。
- 不使用用户数据判断信用度、放贷或用于与单一用途无关的目的。

## 数据存储与删除

设置保存在浏览器为扩展提供的同步存储（`chrome.storage.sync`）中，会随浏览器账号同步；任务状态、任务结果和每日尝试日期保存在本机的扩展存储（`chrome.storage.local`）中，不参与同步。这些数据不经过开发者，开发者无法访问或删除它们。扩展没有提供单独的“一键清除”入口，实际删除方式如下：

- 在扩展弹窗的“设置”中修改或关闭各项任务，只改变设置的取值，不会删除已保存的数据。
- 点击“停止任务”只结束当前这一轮，不会关闭“每日自动执行”，之后的自动检查仍可能开始新一轮；关闭“每日活动”或“领取积分”等任务开关只影响之后的工作，不会中止其中已开始的部分。要阻止后续自动开始，应关闭“每日自动执行”。
- 这些操作都不会清除已经写入的任务记录：任务结果和进度保留在本机，直到下一轮任务开始时被覆盖；每日尝试日期只记录本轮实际尝试过的任务，其他任务的日期仍保留在本机。
- 删除这些数据的可靠方式是在扩展管理页移除本扩展：浏览器会清除该扩展的本机存储，同步保存的设置也会随扩展一并从浏览器账号的同步数据中移除。

扩展不会在开发者侧保留任何用户数据副本，因此不存在需要向开发者申请删除的数据。

弹窗「高级设置 → 诊断信息」提供的导出只由用户主动触发：内容是仅含扩展版本、浏览器 User-Agent（其中带浏览器与操作系统版本等环境信息）、轮次与调度时间、任务状态和结构化错误原因的脱敏快照，不含账号、邮箱、Cookie、令牌、搜索内容或页面内容；导出的是保存在本机的 JSON 文件，可以先预览再导出，导出过程不经过网络，扩展也不会自动生成或发送任何诊断数据。

## 网络访问

扩展会打开 `bing.com` 搜索页和 `rewards.bing.com` 页面，这些请求由用户已登录的浏览器直接向 Microsoft 发出，受 Microsoft 自身的隐私政策约束。扩展不代理、不转发也不记录这些请求的内容。

启用「打开首个搜索结果」后，在找到自然搜索结果时，本轮打开的搜索页会在短暂停留后自动跳转到该次搜索的首个结果网站；该授权在本轮排程结束后仍然有效，任务被停止或关闭「执行搜索」开关后才会撤销。这是一次离开 Bing 的外部导航，目标网站由当时的搜索结果决定；跳转发生后扩展在该页面上不再运行，也不读取其内容。该次访问同样由浏览器直接发出，受目标网站自身的隐私政策约束。

## 儿童隐私

扩展不面向儿童设计，也不会有意收集儿童的个人信息。

## 政策变更

本政策随扩展版本更新。重大变更会更新本文件的生效日期，并在项目仓库中保留历史记录。
