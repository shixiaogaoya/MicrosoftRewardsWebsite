# Rewards 助手隐私权政策

生效日期：2026-11-02

Rewards 助手是一款个人维护的非官方 Microsoft Rewards 浏览器扩展，与 Microsoft 无隶属或背书关系。本政策说明扩展会处理哪些数据、数据存放在哪里，以及用户如何控制这些数据。

## 扩展处理的数据

扩展只处理运行所必需的以下数据：

- **设置项**：是否执行搜索、每日活动、积分领取、每日自动执行，搜索次数、搜索间隔、标签页关闭时间、账号等级、是否打开首个搜索结果。这些设置保存在浏览器的扩展存储（`chrome.storage`）中，供扩展在下次打开或后台定时执行时读取。
- **任务状态**：本轮任务的阶段、已发起的搜索次数、各任务的执行结果（进行中、完成、失败、结果待确认、已取消等）。这些状态只保存在本机浏览器存储中，用于弹窗展示进度和结果。
- **Rewards 页面内容**：扩展在 `rewards.bing.com` 和 Bing 搜索结果页运行时，会读取页面中与积分任务、搜索框和结果链接相关的元素，用来判断任务是否可执行、结果是否出现。读取仅在本机页面内进行。

## 扩展不会做的事

- 不收集、不上传姓名、邮箱、地址、电话号码、账号密码、Cookie 或登录凭据。
- 不向开发者或第三方服务器发送设置、任务状态或页面内容。
- 不包含统计、广告、埋点或远程代码，不加载扩展包以外的脚本。
- 不出售、出租或向第三方传输用户数据。
- 不使用用户数据判断信用度、放贷或用于与单一用途无关的目的。

## 数据存储与删除

设置和任务状态保存在浏览器本地的扩展存储中，随浏览器配置存在。用户可以通过以下方式清除：

- 在扩展弹窗的“设置”中修改或关闭各项任务。
- 在扩展管理页移除本扩展，浏览器会同时清除其扩展存储。
- 在浏览器中清除该扩展的网站数据。

扩展不会在开发者侧保留任何用户数据副本，因此不存在需要向开发者申请删除的数据。

## 网络访问

扩展会打开 `bing.com` 搜索页和 `rewards.bing.com` 页面，这些请求由用户已登录的浏览器直接向 Microsoft 发出，受 Microsoft 自身的隐私政策约束。扩展不代理、不转发也不记录这些请求的内容。

## 儿童隐私

扩展不面向儿童设计，也不会有意收集儿童的个人信息。

## 政策变更

本政策随扩展版本更新。重大变更会更新本文件的生效日期，并在项目仓库中保留历史记录。
